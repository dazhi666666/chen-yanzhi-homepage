# 单人试玩来源与范围

`src/` 和 `assets/art.json` 从用户指定的 `D:\坦克动荡` 复制，原项目未修改。保留的模块为规则核心、默认输入转换、已转换的游戏脚本、碰撞数据、矢量素材、Laika 动画与绘制工具。不包含联网、登录、房间服务或原项目配置凭证。

- `solo-session.ts`：单人模式生命周期与固定 25Hz 时间步，复用 `legacyInput` 默认旧版鼠标摇杆和 `Match` 的 Laika 行为。
- `paint.ts`：按原项目战场绘制方式适配主页画布，保留默认摇杆大小、死区与开火控件，窄屏将操控区放在地图下方。
- `../tank-demo.tsx`：React 画布适配、双指操作、键盘、开始、暂停、重开及卸载清理。

试玩为无声版本，武器采用原单人规则：普通炮弹起始、激光箱子。原项目仍然以多人对战为核心。本模块仅提供单人体验。

每帧清除试玩不需要的输入历史，避免长时间游玩无限积累；因此不提供回放导出。

验证：`node --test tests/tank-solo.test.mjs`（在 homepage 根目录运行）。
